```
1. Click "🔐 Admin Login" in menu
2. Enter: admin / admin123
3. Click login button
4. Session created, redirected to admin panel
```

### **Access Admin Panel:**
```
1. After login, click "⚙️ Admin Panel" in menu

3. Select category
4. Enter count
```
